## 2024-06-28 - Replace multiple Math.max and maps with a single reduce pass
**Learning:** Using `Math.max(...array.map(...))` multiple times across the same array is an O(N) operation for each property but creates unnecessary array allocations. If placed inside a `.map()` block (as it originally was before extracting to a separate object), it compounds into an O(N^2) complexity. Furthermore, the spread operator inside `Math.max` runs the risk of a "Maximum call stack size exceeded" error when parsing large datasets.
**Action:** Always pre-calculate extremes using a single `.reduce()` pass which achieves O(N) time with minimal space complexity. By merging all extremum checks into a single pass, we significantly reduce execution time and avoid potential scale-related runtime errors.
